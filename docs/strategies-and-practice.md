# Strategies and practice

The workspace Strategy tab supports four reviewed, buy-only strategy kinds: scheduled buying, price thresholds, target allocation and cautious accumulation. Approval is the default; automatic practice must be explicitly selected and separately authorized. Strategy versions and saved mandate versions are recorded in each receipt.

`lib/strategy.ts` is a deterministic strategy evaluator with integer cents and basis points. It checks triggers, permission, fresh simulated quotes, allowlist, purchase cap, UTC daily budget, reserve, concentration and target overshoot. `practiceFill` re-evaluates the exact proposal against current evidence, strategy and mandate before updating balances. Changed evidence, revoked permission and replayed approvals cannot fill.

Practice uses $1,000 fake cash and editable fixture prices. Rules, balances, permission and the latest 50 receipts are saved per signed-in owner in practice_sessions. It sends no wallet, broker or blockchain transaction. Revision compare-and-swap prevents overlapping tabs, approvals and background checks from double-spending fake funds. Permission expires after 24 hours; exact approvals expire after 60 seconds. The eight-second foreground loop runs while the workspace is open. Optional background practice uses the existing authenticated worker, waking about every 15 minutes; delays are possible. It never falls back to live execution. Pause stops both loops; revoke also invalidates pending approvals. Changing saved boundaries or confirming a replacement strategy revokes practice permission. Clock, price and scenario changes invalidate pending approvals. Five fixture scenarios exercise normal funds, stale quotes, insufficient cash, daily cap and concentration. Reset is available only when paused and revoked. Export saved receipts before reset.

Only the confirmed strategy persists on this browser. Balances, grants and receipts are page-session state. Export receipts before reloading. Practice receipts are kept separate from server-side live evidence. They never contain invented transaction hashes or chain-confirmation claims.

Directions can be interpreted server-side by Cloudflare Workers AI once the owner configures a free-plan account and private API token. No browser model download or GPU requirement. The server enforces 50 attempted requests per UTC day across the site, 10 per user per day and a 15-second cooldown. Failed requests consume capacity; no automatic retries or paid fallbacks occur. Stay on Workers Free: its provider allowance rejects further usage rather than billing overages. Missing or unsupported rules need clarification. Applying an AI draft never confirms or authorizes it; only separately reviewed structured rules run. Unsupported conditions, news analysis, selling and optimization do not execute. Live mode is unavailable: real authority installation, complete fees, data, accounting and signing still require integration. The engine has no live submission API and practice permission cannot authorize real funds.

The separate permission lab exercises actual wallet, permission and swap runtimes with fixture tokens. This UI simulation is not that contract lab and does not establish a mainnet fill, fee or liquidity guarantee.
